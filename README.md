            MUSIC PLAYLIST MANAGER
==================================================

Prerequisites:
  - GCC / g++ Compiler (MinGW for Windows, or g++ for Linux/macOS)
  - Google Chrome or any default web browser

--------------------------------------------------
BUILD & RUN INSTRUCTIONS
--------------------------------------------------

File required: main.cpp

1. Open your terminal in the project directory 

2. Compile the source code:
   g++ main.cpp -o main_app.exe

3. Run the executable:
   ./main_app.exe

--------------------------------------------------
Note: Running 'main_app.exe' will automatically 
generate the web interface file ('app_interface.html') 
and launch it directly in your default browser.
